# DW_Actividad_Integradora3_KL

Este proyecto consiste en la creación de una aplicación web desarrollada con HTML, CSS, JavaScript, PHP y MySQL, implementando una arquitectura basada en el patrón MVC (Modelo–Vista–Controlador).
El objetivo es estructurar el sistema de forma modular, separando la lógica de negocio, la gestión de datos y la interfaz de usuario para lograr una aplicación organizada, escalable y fácil de mantener.
